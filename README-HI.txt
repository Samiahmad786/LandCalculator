Bihar Jamin Calculator Android project (bilingual)

Features:
- Hindi / English toggle
- Katha + Dhur to Decimal
- Decimal to Katha + Dhur
- Length x Width in feet to Decimal and square feet
- Custom district/village measurement profiles
- Save calculation history locally
- Share calculation text using Android share sheet (WhatsApp can be selected)
- Generate and share a PDF report
- No internet permission; app calculations are offline

Build APK:
1. Upload project contents to a GitHub repository (the folder containing settings.gradle.kts should be repository root).
2. Open Actions > Build Android APK > Run workflow.
3. Download artifact Bihar-Jamin-Calculator-APK and extract app-debug.apk.
4. Install APK on Android. Allow install from this source if Android asks.

Default profile is 1 Katha=1620 sq ft, 1 Dhur=81 sq ft, 1 Decimal=435.6 sq ft, based on the user's supplied local conversion notes.
All other district/village values must be verified with local revenue records or a qualified amin; do not assume a district has one uniform value.
